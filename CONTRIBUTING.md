# Contributing

1. Keep the implementation dependency-free unless a new dependency has a clear justification.
2. Run `npm test` and `npm run check` before submitting changes.
3. Verify PowerShell syntax with the command documented in `README.md`.
4. Never commit `.runtime/`, `logs/`, local user identifiers, credentials, or vendor binaries.
5. Document behavior changes caused by new HONOR PC Manager or WorkStation versions.
